# 1 из 8 миллиардов — мобильная версия

> Проживи одну случайную жизнь среди 8 миллиардов. Браузерный симулятор судьбы на основе реальной статистики ООН, ВОЗ и Всемирного банка. Полностью переработан под телефон.

**Живая демо:** открой `index.html` на телефоне или через GitHub Pages (включи Pages в настройках репо). Устанавливается как PWA — «Добавить на главный экран».

---

## Что за игра

Ты не выбираешь, где родиться. Страна, пол, деревня/город и достаток семьи выпадают случайно — с реальным шансом по рождаемости (Индия — 17% всех рождений, Исландия — 1 из ~33 000). Дальше год за годом принимаешь решения карточками: учёба, работа, любовь, переезд, здоровье. 4 показателя — ♥ здоровье, ☺ счастье, ◐ отношения, ◆ деньги — меняются от выбора и влияют на шанс дожить до старости. В конце — карточка памяти, которой можно поделиться.

Оригинальный виральный хит октября 2026 (1in8b.life, 1in8b.app). Эта версия — **максимально адаптированный для телефона** ремейк без фреймворков, офлайн.

## Как максимально адаптировали под телефон

Цель: ощущается как нативное приложение, а не «сжатый десктоп». Всё ниже — уже сделано:

### 1. Лейаут и вьюпорт
- **Mobile-first, 320 → 520 px** — единственный брейкпоинт. Контент центрирован, 100% ширины на телефонах, не разъезжается на планшетах.
- `viewport-fit=cover` + `env(safe-area-inset-*)` — учитывает вырез (notch/Dynamic Island) и жестовую полосу iPhone/Android. Топбар и нижняя навигация не перекрываются.
- `100dvh / 100svh` вместо `100vh` — нет прыжков при появлении клавиатуры/адресной строки Chrome/Safari.
- `interactive-widget=resizes-content` — клавиатура не ломает лейаут поиска страны.
- `overscroll-behavior: contain` + блокировка pull-to-refresh на игровом поле.

### 2. Управление одной рукой
- **Свайп-карточки как в Tinder:** `pointerdown / pointermove / pointerup` (единый код для мыши и тача), `setPointerCapture`, порог 82 px + velocity, поворот `rotate(±18deg)`, подсказки `← / →` проявляются при драге, возврат с пружиной.
- Дублирующие **кнопки 56 px** внизу — для доступности и тех, кто не любит свайп. Стрелки клавиатуры тоже работают.
- Все интерактивные элементы ≥ 44–56 px, `touch-action: manipulation`, `-webkit-tap-highlight-color: transparent`, скругления 16–24 px под палец.
- **Haptics:** `navigator.vibrate(10–20 мс)` на свайп/выбор/рождение/смерть. На iOS — деградация без ошибок.
- Нижняя навигация **фиксирована** над жестовой полосой (`padding-bottom: safe-area`), доступна большим пальцем. История — шторка (bottom sheet) с ручкой.

### 3. Типографика и читаемость
- База 15–16 px (16 px в `<input>` — iOS не зумит при фокусе), заголовки `Cormorant Garamond`, body `Manrope`.
- Контраст ≥ 4.5:1, системная тёмная тема (`prefers-color-scheme`), ограничение длины строки 520 px.
- **Ландшафт-блокер:** на маленьких высотах просит повернуть в портрет — игра создана для вертикали.

### 4. Производительность и офлайн
- **Без фреймворков** — чистые HTML/CSS/JS ES-модули. Старт < 50 KB gzip, нет CLS, анимации только `transform/opacity` на GPU.
- PWA: `manifest.json` (`display: standalone`, `orientation: portrait`, shortcuts), `sw.js` кэширует всё, игра работает в самолёте. `theme-color` адаптируется под тему.
- Шрифты через `preconnect` + `display=swap`, иконки — inline SVG/эмодзи (нет запросов).

### 5. Нативные интеграции
- **Canvas 1080×1350** — автогенерация карточки для сторис/соцсетей, шаринг через Web Share API (`navigator.share({files})`) с фолбэком на скачивание.
- Web Share, Vibration, Clipboard, `apple-mobile-web-app-*` мета, `format-detection=no`.
- Сохранение только на устройстве (`localStorage`), никакого трекинга.

### 6. Игровая адаптация
- Прогресс-бар жизни, компактный pill с 4 шкалами (липкий под топбаром).
- Поиск стран с дебаунсом 160 мс, `inputmode=search`, табы «Все / Чаще всего / Редкие».
- Авто-режим с паузой при `visibilitychange`, скорость 1×/2×/4×.
- Архив с экспортом `.txt`, удаление, просмотр.

## Структура проекта
```
index.html      — shell, все экраны (home/picker/birth/game/death/archive), мета для PWA/iOS
css/style.css   — дизайн-система: переменные, safe-area, сетки, карты, шторки, тёмная тема
js/data.js      — 100+ стран с весами ООН, имена по регионам, ~35 событий по возрастам
js/app.js       — движок жизни, свайпы, прогресс, архив, шаринг, авто-игра
manifest.json   — PWA-манифест
sw.js           — Service Worker (офлайн-кэш)
```

## Запуск локально
```bash
# любой статический сервер
python3 -m http.server 8000
# или
npx serve .
```
Открой `http://localhost:8000` на телефоне (в одной сети) или используй Live Preview в Arena.

Для GitHub Pages: Settings → Pages → Deploy from branch → `arena/63846101-1in8b-mobile` (или `main` после мержа) → `/ (root)`.

Что адаптировано под телефон

Оригинал 1in8b.life делался для десктопа. Мы не переписывали механику — только подложили мобильные фиксы поверх. Патчи — в css/adapter.css + js/adapter.js.

1. Вьюпорт и safe-area

  • viewport-fit=cover + env(safe-area-inset-*) — топбар/низ не режутся вырезом и жестовой полосой
  • 100dvh/100svh вместо 100vh — нет прыжков при клавиатуре
  • interactive-widget=resizes-content — клавиатура не ломает поле ввода

2. Тачи и управление

  • touch-action: manipulation, -webkit-tap-highlight: transparent, overscroll-behavior: contain
  • Все кнопки ≥48px, межкнопка ≥8px, скругления под палец
  • Haptics navigator.vibrate(10) на действия (прозрачный фолбэк на iOS)
  • Горизонтальный свайп не конфликтует с вертикальным скроллом

3. Производительность и PWA

  • manifest.json (standalone, portrait, shortcuts), theme-color под тему
  • sw.js кэширует оболочку — оффлайн-скрин с кнопкой перехода остаётся
  • Шрифты с preconnect, иконки inline — 0 лишних запросов

4. Доступность

  • Оригинальный контент не трогаем, только обвязка. Ландшафт — плашка «поверни»
  • Внешние ссылки с rel=noopener, фокус-стили, 16px в input (без зума на iOS)

Хочешь проверить? Открой DevTools → Toggle device toolbar → выбери iPhone 13 / Pixel 7 и сравни с оригиналом без обёртки.
